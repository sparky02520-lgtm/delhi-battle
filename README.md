# Delhi Battle v0.12 — Five Arenas

- Five selectable maps with distinct collision layouts: Parliament District, India Gate Battlefield, Political Rally Ground, Epstein Island, and Futuristic Tech Lab.
- Each arena has its own platforms, barriers, bushes, pickups, palette, landmark and satirical signage.
- Retains v0.11 caricature fighters, character/team selection, abilities, automatic/manual reload, mobile controls, jetpack and training bot.

## Controls
Desktop: A/D or arrows move; Space/W/Up jump; Shift jetpack; mouse aim/fire; R reload; G grenade; Q special; X ultimate.
Mobile: move and aim/fire joysticks plus action buttons.

## Current limitations
Offline prototype with one training bot. Online multiplayer, full five-player teams, and arena-specific interactive events are not implemented yet. This build should be browser-tested on every arena before treating it as fully verified.
