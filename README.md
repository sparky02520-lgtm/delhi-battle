# Delhi Battle — v0.9 Ground, HUD & Touch Controls Fix

This build adjusts the ground line so the character's full body has more visible space above the ground, makes the HUD more compact, and moves mobile controls farther inward. The action buttons are grouped next to the right aim joystick rather than spread across the middle of the screen.

## Controls
- Desktop: A/D or arrow keys to move, Space/W/Up to jump, Shift to use jetpack, mouse to aim/fire, R to reload, G to throw grenade, E to trigger a nearby security console.
- Mobile landscape: left joystick to move; right joystick to aim/fire; JUMP, JET, FIRE, GREN and RELOAD grouped beside the right joystick.

## Install
Replace `index.html`, `style.css`, `game.js`, and `README.md` at the root of the existing GitHub Pages repository, then commit the changes.

This is still an offline prototype with one training bot. The ZIP and JavaScript syntax can be checked locally, but test on your target phone/browser to confirm the layout and collision visually.
