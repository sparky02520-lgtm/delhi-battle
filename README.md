# Delhi Battle — Landscape Combat Build 0.2

A playable browser prototype for an original 2D side-view action shooter with a fictional political-satire setting inspired by Delhi civic architecture.

## Controls
- Desktop: A/D or arrows to move, Space/W/Up to jump, double jump while airborne, Shift for jetpack, mouse to aim/fire, R reload, G grenade, F melee.
- Mobile: rotate to landscape; left joystick moves, right joystick aims and fires, buttons handle jump, jetpack, grenade and melee.

## Current features
- Landscape-first mobile layout with safe-area-aware touch controls.
- Portrait orientation prompt and best-effort fullscreen/orientation lock.
- Higher jump and double jump to reach raised platforms.
- Fictional satirical Parliament District scene, rally barricades, fictional signs, jetpack, shooting, grenade and melee.
- Local training bot only. Online multiplayer is not connected yet.
