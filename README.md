# Delhi Battle v0.13 — Compact HUD & Pause Menu

## Changes
- Smaller player and opponent HP HUD cards and a more compact match panel.
- Temporary notifications appear near the top of the gameplay view with a translucent background, keeping the center of the action visible.
- Added an in-game pause/menu button.
- Pause menu actions: Resume, Restart Match, Change Arena/Fighter, and Main Menu (returns to setup).
- Keyboard: `Esc` or `P` pauses/resumes.
- Existing five arena selection, fighters, abilities, weapons, movement, and reload features are retained.

## Install
Replace `index.html`, `style.css`, `game.js`, and `README.md` at the root of the existing GitHub repository, then commit the changes.

## Testing note
JavaScript syntax and ZIP integrity were checked. Full browser/mobile gameplay testing has not been completed.
