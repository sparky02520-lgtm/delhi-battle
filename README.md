# Delhi Battle — v0.4 Political Showdown Prototype

A browser-based 2D side-view action prototype designed for landscape mobile play and desktop browsers.

## Included in this build
- Landscape-oriented mobile layout with dual virtual joysticks and action buttons.
- Arena selection: Parliament District, India Gate Battlefield, and Political Rally Ground.
- Three selectable fictional fighter looks: Street Runner, Capital Guard, and Rally Rebel.
- Local training bot, shooting, reload, grenades, melee, double jump, and jetpack.
- Increased jump height and more reliable one-way platform landing checks.
- Fictional political satire signage and original canvas-drawn environments.

## Controls
- Desktop: A/D or arrows to move, Space/W/Up to jump (press again for double jump), Shift to use jetpack, mouse to aim/fire, R reload, G grenade, F melee.
- Mobile: rotate to landscape, use left joystick to move and right joystick to aim/fire; use the action buttons.

## Run locally / GitHub Pages
Keep `index.html`, `style.css`, `game.js`, and `README.md` together in the repository root. GitHub Pages can host this static prototype.

## Limitations
This remains a local training prototype with one bot. Arena selection changes the environment art, and fighter selection changes the player's colors; these are not yet separate gameplay modes or unique character abilities. Online multiplayer, matchmaking, persistent profiles, and real backend services are not implemented. A realtime backend is required for online matches.

All political signs and factions are fictional. Real landmarks are represented in stylized, original artwork. This is an independent fan-made prototype and is not affiliated with Mini Militia or any political party.
