# Delhi Battle v0.14 — Arcade Polish

## Updates
- Reduced both player and opponent health HUD panels again.
- Repositioned notifications to the left side of the play area, below the top HUD, with a translucent comic speech-bubble treatment.
- Added brief comic-book combat callouts such as POW!, BAM!, BONK!, OOF!, PEEKABOO! and K.O. near hit characters.
- Added animated arena ambience: Parliament searchlights, India Gate drifting smoke/searchlight, rally confetti, island water glints/birds, and tech-lab scan lines.
- Retained pause/resume, restart, arena/fighter selection, combat and existing controls.

## Controls
Desktop: A/D or arrows to move, Space/W to jump, Shift to jet, mouse aim/fire, Q special, X ultimate, R reload, G grenade, E console event, Esc/P pause.
Mobile: use the on-screen joysticks and action buttons.

## Install
Replace `index.html`, `style.css`, `game.js`, and `README.md` at the root of the existing GitHub repository, then commit changes.

## Status
Offline single-player prototype with one training bot. JavaScript syntax and archive integrity should be checked before release; full browser/device playtesting is still recommended.
